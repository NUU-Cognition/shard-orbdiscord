# OrbDiscord

OrbDiscord shard

## Structure

```
Shards/(Dev Local) OrbDiscord/
  shard.yaml                    # Manifest (not prefixed)
  RELEASE.md                    # Optional release changelog (not prefixed)
  dev-init-odisc.md      # Init file — shard context
  dev-hinit-odisc.md     # Optional headless init
  skills/                       # dev-sk-odisc-{name}.md
  workflows/                    # dev-wkfl-odisc-{name}.md, dev-hwkfl-odisc-{name}.md
  templates/                    # dev-tmp-odisc-{name}-v<X.Y>.md
  knowledge/                    # dev-knw-odisc-{name}.md
  assets/                       # dev-ast-odisc-{name}.{ext}
  install/                      # type-odisc-{name}.md (NOT prefixed)
  migrations/                   # dev-mig-odisc-{from}-to-{to}.md
  scripts/                      # dev-{name}.js
```
